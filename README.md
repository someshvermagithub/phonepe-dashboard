# 📊 PhonePe Dashboard

An interactive **PhonePe-inspired payment analytics dashboard** built using **Power BI** and **Microsoft Excel**, showcasing UPI transactions, QR payments, and insightful financial visualizations.

---

## 🚀 Features

* 📱 UPI Transactions Analysis
* 🔍 QR Payment Insights
* 📈 Interactive Dashboards & Filters
* 💰 Revenue & Transaction Trends
* 🧾 User Behavior Analysis

---

## 🛠️ Tech Stack

* **Power BI** – Data visualization & dashboard creation
* **Microsoft Excel** – Data cleaning & preprocessing
* **Python** – Data cleaning & feature engineering
